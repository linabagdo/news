В конфиге:
listen_port - внутренний порт
is_verbose - если поменять true на false в log будет записываться факт каждого приходящего сообщения
is_writing - для включения записи

В compose:

11, 12, 13 - папки, в которые пробрасываются логи и папки с трафиком

Факт возникновения потерь записывается в log c их количеством
